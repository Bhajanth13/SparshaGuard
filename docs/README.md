# docs/

| Folder | What is in it |
|---|---|
| `technical/` | `design_notes.md` (hardware, flagship architecture, Gate 1 test rules) and the write-up of each study: `whole_body_detection.md`, `whole_body_fusion.md`, `new_channels.md`, `findings_integrated_v0_3.md`; `consistency_pass_2026-11-06.md`; the one-page `project_map.svg` |
| `sources/` | `parameter_sources.md` (every value and its source) and the two workbooks of paper values, built by `tools/build_sources_xlsx.py` and `tools/build_paper_values_xlsx.py` |
| `pitch/bih2026/` | Bharath Innovate Hackathon 2026 deck and its 3.5-minute script |
| `pitch/anvaya2k26/` | ANVAYA 2k26 deck: the HTML deck is the master; the PDF and PPTX are exports of it; 5-minute script |
| `pitch/video_script_2min.md` | Narration and shot list for the 2-minute video (`media/videos/demo_2min/`) |

Numbers in the decks and scripts come from `results/data/headline_numbers.json`; the BIH deck is
updated by `python tools/update_bih_deck.py`.
