# Earlier explainer video (outdated)

`SparshaGuard_Explained.mp4` (13 minutes), its offline page `SparshaGuard_Explained.html` and
`narration_script.md` were made before the 3D field calculation was put into the model
(12 October 2026). They say a forearm grab changes the sensor reading by "about a quarter of a
percent"; the current model, checked with FastCap, puts it at the noise floor (~0.1 %), so the
wrist sensor does not see forearm grabs. Everything else in the video still holds.

For the current story, use the digital-twin demo (`demo/sparshaguard_demo.html`) and the
2-minute script in `docs/video_script_2min.md`. The video's source code lives outside this repo.
