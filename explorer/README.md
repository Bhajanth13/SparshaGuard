# explorer/ (the physics explorer web page)

Live at https://bhajanth13.github.io/SparshaGuard/explorer/. Open `sparshaguard_explorer.html` to
use it offline. That file is generated: edit the sources, then run `python tools/build_explorer.py`.

| File | What it is |
|---|---|
| `page_src.html` | Page layout and charts |
| `model.js` | JavaScript port of `simulation/sg_model.py`; keep the two in step |
| `index.html` | Redirect so the short `/explorer/` link works |
